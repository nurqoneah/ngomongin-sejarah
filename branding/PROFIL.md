## Checklist bikin akun

> Login, password, dan verifikasi nomor HP/email dilakukan sendiri ya.

- [ ] **Email khusus** untuk channel (misal Gmail baru) supaya semua akun nyambung ke satu email
- [ ] **YouTube:** login Gmail → youtube.com → Buat channel → nama "Ngomongin Sejarah" → set handle `@ngomonginsejarah` → upload foto profil + banner + deskripsi
- [ ] **Instagram:** daftar → ganti ke **Akun Profesional → Kreator** (biar dapat statistik) → foto profil + bio
- [ ] **Facebook:** dari akun FB pribadi → Halaman → Buat Halaman Baru → foto profil + sampul + bio → hubungkan ke IG (Meta Business Suite) supaya Reels bisa diposting sekaligus
- [ ] **TikTok:** daftar → ganti ke **Akun Bisnis/Kreator** → foto profil + bio
- [ ] Taruh link antar-platform di bio (YouTube ↔ IG ↔ TikTok)

## Tips upload

- **Video sama** (9:16, 86 detik) bisa dipakai di keempat platform.
- **Musik:** tambahkan dari library musik bawaan aplikasi (TikTok / IG / YouTube) pas upload, biar aman hak cipta dan ikut tren. Volume pelan, sekitar 10–15%.
- **Label AI:** suara narasi dibuat pakai TTS (AI). Kalau aplikasi menanyakan (TikTok: "Konten buatan AI", YouTube: "Konten sintetis/diubah"), lebih aman centang.
- **Cover/thumbnail:** pilih frame "313 VS ±1000" di detik awal.
- Posting di jam ramai: **sore 16.00–18.00** atau **malam 19.00–21.00 WIB**.
